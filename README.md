# 🦆 Psyduck 1st Edition Price Tracker

Dashboard tracking the TCGPlayer market price of **Fossil 1st Edition Near Mint Psyduck (53/62)** over time.

## [Live Dashboard →](https://psyduckler.github.io/psyduck-price-tracker/)

## Features
- 📈 Interactive price chart with 7D/30D/90D/6M filters
- 💰 Current price, change percentages, high/low
- 📊 Price statistics (average, median, data points)
- 📱 Fully responsive
- 🌙 Dark theme

## Data
Price data sourced from [JustTCG](https://justtcg.com) (TCGPlayer market prices). Updated on request.

## Tech
Static HTML + Chart.js. No build step, no dependencies beyond Chart.js CDN.
